# Glow-Skin-Care-Recommendation
Glow Skin Care Recommendation – A machine learning-based web application that provides personalized skincare recommendations based on users' skin type and concerns, helping them choose suitable products and routines.

## Features

- Personalized skincare recommendations
- Skin type analysis (Oily, Dry, Combination, Normal)
- Skin concern detection and suggestions
- User-friendly interface
- Fast and accurate recommendations
- Machine Learning-based prediction system

## Tech Stack

- Python
- Machine Learning
- Flask
- HTML
- CSS
- JavaScript
- SQL Database

## How It Works

1. User enters skin details and concerns.
2. The system analyzes the input data.
3. Machine Learning model processes the information.
4. Personalized skincare recommendations are generated.
5. User receives suitable product and routine suggestions.
